# Security policy

## Supported version

Security fixes are applied to the latest revision of the `main` branch.

## Reporting

Use [GitHub private vulnerability reporting](https://github.com/arar228/armk-b2b-showcase/security/advisories/new). Include the affected path, expected impact, and a minimal reproduction.

## Scope

This repository is a standalone showcase with synthetic data. It has no production credentials, production database connection, customer records, or deployment access.
